# LibraryProject

This project is a basic Django setup created as part of the ALX Django learning lab.

## Requirements

- Python
- Django

## Installation

Install Django using pip:

pip install django

## Create Project

django-admin startproject LibraryProject

## Run Server

cd LibraryProject
python manage.py runserver

Then open:

http://127.0.0.1:8000/

## Project Structure

manage.py  
Command-line utility used to interact with the Django project.

settings.py  
Contains configuration settings for the Django project such as installed apps and database configuration.

urls.py  
Defines URL routes for the project.

wsgi.py  
Entry point for WSGI-compatible web servers.

asgi.py  
Entry point for ASGI-compatible web servers.
